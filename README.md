# Law Zava

I write about putting AI into production: operating models, technical leadership, reliability, cost, and infrastructure. The writing lives at [lawzava.com](https://lawzava.com).

Most of my engineering work happens in private company repositories. The public repositories here are tools I built for my own use and still maintain:

- [megapowers](https://github.com/lawzava/megapowers): one plugin for Claude Code and Codex with task skills, an output style, and a destructive-command tripwire. Each claimed effect has an eval you can re-run.
- [mindline](https://github.com/lawzava/mindline): peer-to-peer chat, end-to-end encrypted, where messages appear as they are typed. Live at [mindline.chat](https://mindline.chat).
- [subswapper](https://github.com/lawzava/subswapper): runs several Claude Code and Codex accounts on one machine and picks the least-used one.
- [mynews](https://github.com/lawzava/mynews): RSS and Atom feeds filtered by keyword or relevance score, sent to Telegram, Discord, Slack, or a webhook.
- [go-pg-migrate](https://github.com/lawzava/go-pg-migrate): PostgreSQL migrations for Go, listed in [Awesome Go](https://awesome-go.com).
- [scrape](https://github.com/lawzava/scrape) and [emailscraper](https://github.com/lawzava/emailscraper): a Go CLI and library that find the email addresses a website publishes.
